# DP BARREL & SPIRIT — Главный мануал проекта

Этот документ содержит все необходимые инструкции по архитектуре, дизайну, работе с ИИ-агентами и подготовке контента для создания нового сайта бренда с абсолютного нуля.


##  ИНСТРУКЦИЯ ДЛЯ АГЕНТОВ (КОНТЕКСТ И ФИЛОСОФИЯ)

Эту часть (или весь документ) вы скармливаете ИИ перед началом написания кода.

**Суть бренда:** "Crafted by Nature. Aged by Time."
Проект транслирует эстетику реальной мастерской, ручного труда и премиального ремесла (Dark Craft). Главный актив — настоящие изделия. AI не должен быть главным героем, никаких пластиковых 3D-рендеров.

**Структура одностраничного сайта (5 блоков):**

1. **Hero:** Видеофон мастерской (затемнение фона максимум 20-25%). Текстовый логотип, крупный заголовок, слоган. Минимализм, без пустых кнопок и 3D-моделей.

2. **Collection (Горизонтальный скролл):** Крупные фото бочек разных объемов, листающиеся вбок (нативный CSS scroll, без тяжелых библиотек).

3. **Gallery (Асимметричная плитка):** Крупные планы (макро) текстуры дубдерева, кранов, заклепок (чередование квадратов 1:1 и вертикалей 4:5).

4. **Workshop & Craft:** Описание процесса, обжига, .

5. **Footer:** Лаконичные контакты и соцсети.

**Технические правила для Агента:**

* Писать чистый код (Next.js + Tailwind CSS).

* Никаких неработающих кнопок или фейковых ссылок.

* Использовать `next/image` для всех картинок.

* Мобильный адаптив обязателен (Mobile-first).

## ЧАСТЬ 3. ПРАВИЛА РАБОТЫ С ФОТО И АПСКЕЙЛОМ 

Приоритет: `REAL PHOTOGRAPHY > AI GENERATED VISUALS`.


### 3.1. Форматы и сетка пропорций

Оставляйте исходники в **PNG** (без фона или с ним). Next.js сам переконвертирует их в WebP без потери качества при загрузке сайта.

* **Hero (Бочка):** Свободная форма (вырезанный PNG), размер до 2000px по ширине.

* **Collection (Карточки бочек):** Пропорция `3:4` или `4:5` (вертикальные). Идеально для мобильного скролла.

* **Gallery (Макро-детали):** Пропорция `1:1` (квадрат) для донца/кранов, `4:5` для текстуры дерева.

## ЧАСТЬ 4. ДИЗАЙН-СИСТЕМА (DESIGN.md)

Никакого жесткого черного (#000000) и кислотно-оранжевого. Только глубокие, благородные оттенки погреба и бондарной мастерской.

### 4.1. Цветовая палитра

* **Базовый фон:** `Charcoal Base (#11100E)` или `Surface (#141311)`.

* **Заголовки и акценты текста:** `Warm Ivory (#EDE8DF)` / `On-surface (#E6E2DE)`.

* **Основной текст (Описания):** `Raw Canvas (#D1CBC0)`.

* **Логотип, кнопки и линии:** `Distiller's Copper (#B87333)` и `Toasted Honey (#D49B5B)`.

* **Обводки:** `Muted Warm Gray (#9E988F)` или `Antique Bronze (#8A5A36)`.

### 4.2. Типографика

* **Заголовки (H1-H3):** `Playfair Display`. Элегантный, с засечками, передает историчность и премиальность. Главный заголовок в Hero — размер `56px` (Desktop).

* **Основной текст и UI:** `Plus Jakarta Sans` или `Inter`. Читабельный, чистый гротеск для контраста с заголовками.

### 4.3. Эффекты и освещение

* Тени должны быть мягкими, глубокими.

* Для имитации бликов огня на металле использовать CSS-оверлеи (`mix-blend-mode: color-dodge`) с теплым янтарным цветом (`#E58A2B`) и мягкой анимацией прозрачности.

* Отказаться от агрессивного Glassmorphism (эффекта матового стекла) в пользу текстуры дерева.
